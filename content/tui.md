## Что внутри

- **Сетевые тулзы host.pink**: досье IP, домена, AS и префикса, проверка доступности из российских сетей и из мира, DNS, TCP-пинг. Отчёты приходят потоком, как в браузере.
- **База знаний**: поиск по BedolagaBD и гайдам, вопросы к ИИ со ссылками на источники.
- **Плагины**: скрипты сообщества в одном меню. Каждый закреплён на коммите и проверяется по SHA-256 перед запуском.
- **Без рекламы, трекеров и телеметрии.** Клиент ходит только на host.pink и за файлами плагинов на GitHub.

Работает в любом терминале. Если анимации мешают (медленный SSH, старая консоль), запускай с `--no-anim` или задай `HOSTPINK_NO_ANIM=1`. `NO_COLOR` тоже выключает анимации.

## Команды

```text
hostpink                         интерфейс
hostpink plugins                 список плагинов
hostpink run reshala             запустить плагин без интерфейса
hostpink run yabs fast           …с конкретным действием
hostpink add github.com/o/r      добавить плагин из git (нужен hostpink.toml)
hostpink registry add github.com/o/r   подключить сторонний реестр
hostpink update                  обновиться с проверкой контрольной суммы
```

## Безопасность

Плагины запускают чужой код, часто от root. hostpink не делает его проверенным, но делает предсказуемым:

1. Плагин закреплён на полном SHA коммита. Файлы скачиваются по неизменяемому адресу и сверяются по SHA-256 из реестра. Хэш не совпал — запуск отменяется.
2. Перед запуском видно репозиторий, коммит, файлы, точную команду и предупреждения: «нужен root», «сам докачивает код из своей ветки».
3. Код можно прочитать прямо в интерфейсе (клавиша `v`).
4. Обновления плагинов не ставятся молча: новый коммит попадает в [реестр](https://github.com/Rxflex/hostpink-registry) только через pull request.

Установщик hostpink тоже сверяет SHA-256 бинарника перед установкой. Исходники клиента лежат в [монорепозитории host.pink](https://github.com/Rxflex/host.pink/tree/main/tui).

## Написать свой плагин

Положи в корень репозитория `hostpink.toml`:

```toml
title = "Мой инструмент"
description = "Что делает и где запускать"
category = "Проверки"
platforms = ["linux"]
needs_root = true
files = [{ path = "install.sh" }]

[[actions]]
id = "install"
title = "Установить"
run = "bash install.sh"
```

Любой сможет поставить его командой `hostpink add github.com/you/repo`: плагин закрепится на текущем коммите, а хэши файлов запомнятся. Чтобы попасть в общий каталог, открой pull request в [hostpink-registry](https://github.com/Rxflex/hostpink-registry). Свой реестр — это любой репозиторий с файлом `hostpink-registry.json` в корне.
