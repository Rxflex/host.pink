## Как этим пользоваться

Вбей в строку сверху что угодно: `1.1.1.1`, `example.com`, `AS13335`, `1.1.1.0/24` или вопрос словами. Строка сама поймёт, что это, и откроет нужную страницу. То же работает адресом: `host.pink/example.com`.

```bash
curl host.pink/ip
```

```bash
curl host.pink/dns/example.com
```

Добавь `?json` к любому адресу, если нужен JSON для скриптов.

## Честно о том, что под капотом

- **Пинг здесь TCP**, не ICMP: в Cloudflare Workers нет сырых сокетов. Меряем время TCP-рукопожатия с того дата-центра Cloudflare, куда пришёл твой запрос. Для «жив ли порт» этого хватает, для поиска потерь на маршруте — нет, там нужен `mtr`.
- **Проверку из разных стран** делают пробы [Globalping](https://globalping.io): тысячи точек по миру, в России их больше полутора сотен, включая домашних провайдеров. Там видно блокировки ТСПУ так, как их видят обычные абоненты. Одинаковые проверки кешируем на две минуты: бесплатный лимит у Globalping почасовой. Если Globalping недоступен, честно проверяем из одной точки — дата-центра Cloudflare.
- **BGP и ASN** берём из [RIPEstat](https://stat.ripe.net) и [bgp.tools](https://bgp.tools). Если нужна глубина, иди к ним напрямую, мы даём ссылки.
- **Лимиты**: на тулзы действует ограничение запросов с одного IP. Хочешь мониторинг раз в секунду — подними свой Uptime Kuma.
